## 💡 DESIGN NOTES

**Gedung Sate Silhouette Key Features:**
- Art Deco style building (1920s architecture)
- Distinctive satay-shaped spire on top (most recognizable element)
- Symmetrical facade
- Located in Bandung, West Java - iconic government building
- Represents Indonesian governance and cultural heritage

**Mega Mendung Pattern:**
- Traditional Javanese/Sundanese cloud motif
- Swirling, curved cloud shapes
- Use as subtle texture, NOT dominant pattern
- Represents Indonesian cultural identity

**Sundanese Woman Characteristics:**
- Ethnicity from West Java (Sunda region)
- Professional, modern Indonesian woman
- Hijab styling: Contemporary, not traditional/rural
- Represents diversity and inclusivity in civic service
