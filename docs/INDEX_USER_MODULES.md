# INDEKS RESMI DOKUMEN MODUL PENGGUNA (USER MODULES) BUMI WARGA
## EKOSISTEM PELAYANAN ADMINISTRASI KEPENDUDUKAN & KESEHATAN DIGITAL
### Pemerintah Kota Sukabumi — Jawa Barat | Edisi 2026

Seluruh modul panduan teknis pengguna (*User Modules*) aplikasi **Bumi Warga** telah disusun secara rinci dan terpisah ke dalam berkas Markdown (`.md`) untuk masing-masing peran pengguna (*role*). Setiap modul memuat navigasi menu, langkah operasional tombol demi tombol, panduan visual alur *mermaid*, kebijakan keamanan akun, serta **hal-hal kritis yang wajib diperhatikan** oleh masing-masing pengguna.

| No | Peran Pengguna (*Role*) | Berkas Dokumen Modul | Ringkasan Isi Panduan & Hal Kritis |
