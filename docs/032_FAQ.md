# Frequently Asked Questions (FAQ)

---

### Q1: What infrastructure do I need to run WK Community OS?

**A:** You do not need any physical servers. The entire application runs on a Google Workspace account. You only need a modern web browser and an internet connection to use it. See `022_SYSTEM_REQUIREMENTS.md` for details.

### Q2: Is my data secure?

**A:** Yes. The platform is built on Google's secure infrastructure. All data is stored within your own Google Workspace account, and access within the application is controlled by a strict Role-Based Access Control system. See `030_SECURITY_GUIDE.md` for more information.

### Q3: Can the letter templates be customized?

**A:** Yes. The letter templates are standard Google Docs. An administrator with access can edit the Google Doc templates to change the layout, wording, or add new logos. The placeholder variables (e.g., `{{citizen.name}}`) must be kept intact.

### Q4: What happens if a scheduled task (trigger) fails?

**A:** You can view the reason for the failure in the "Executions" section of the Google Apps Script editor. Common reasons include exceeding API quotas or temporary Google service outages. The system is designed to be resilient, and tasks like event processing will catch up on the next successful run. See `033_TROUBLESHOOTING.md` for common errors.

### Q5: How do I back up my data?

**A:** The `Deployment` package includes a `BackupService`. An administrator can trigger a full system backup, which will be saved as a file in your designated Google Drive backup folder. See `027_MAINTENANCE_GUIDE.md` for instructions.

### Q6: How many users can the system support?

**A:** The system's capacity is primarily limited by Google Apps Script and Google Sheets quotas. For a typical Kelurahan, these quotas are more than sufficient. For very large-scale deployments (e.g., city-wide), a performance review and potential upgrade to a full Google Cloud Platform backend may be necessary.
