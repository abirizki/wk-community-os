## 1. Overview

This document provides a high-level timeline for the Kebonjati Pilot, broken down into key phases and milestones.

**Total Duration:** 4 Weeks

---

## 2. Pilot Phases

### Phase 1: Preparation (Week 0)
*   [ ] **W0-D1:** Finalize pilot scope, users, and success criteria.
*   [ ] **W0-D2:** Deploy application to the pilot environment.
*   [ ] **W0-D3:** Run all system migrations and seed demo data.
*   [ ] **W0-D4:** Create and verify all pilot user accounts.
*   [ ] **W0-D5:** **Milestone: Pilot Environment Ready & Signed Off.**

### Phase 2: Onboarding & Training (Week 1)
*   [ ] **W1-D1/D2:** Conduct training sessions for Kelurahan staff and RWs.
*   [ ] **W1-D3/D4:** Conduct training sessions for RTs and selected citizens.
*   [ ] **W1-D5:** **Milestone: Pilot Kick-off.** System is officially live for pilot users.

### Phase 3: Active Use & Monitoring (Week 2 - 3)
*   [ ] **W2-D5:** Weekly check-in meeting #1. Gather initial feedback.
*   [ ] **W3-D5:** Weekly check-in meeting #2. Review issue log and usage statistics.
*   [ ] **W3-D5:** **Milestone: Mid-point Review.**

### Phase 4: Evaluation & Wrap-up (Week 4)
*   [ ] **W4-D1:** Distribute final evaluation forms to all users.
*   [ ] **W4-D3:** Conduct final stakeholder meeting to present findings.
*   [ ] **W4-D4:** Analyze results against success criteria.
*   [ ] **W4-D5:** **Milestone: Final Pilot Report & Go/No-Go Recommendation.**
