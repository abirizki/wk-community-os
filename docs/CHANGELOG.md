## [1.0.0] - 2026-08-03

### Added
- **Initial Release ("Kebonjati Pilot")**
- **Citizen Package:** Core module for managing citizen and household data.
- **Letter Package:** End-to-end digital letter request and generation service.
- **Complaint Package:** Structured public complaint management system.
- **Workflow Package:** Universal, state-driven approval engine.
- **EventBus Package:** Asynchronous communication backbone for all modules.
- **Notification Package:** Unified communication center for multi-channel notifications.
- **Analytics Package:** Performant, cached data aggregation and reporting engine.
- **Dashboard Package:** Reusable presentation layer and widget library.
- **DemoData Package:** Comprehensive seeder for generating realistic pilot data.
- **Deployment Package:** Toolkit for managing deployments, backups, and health checks.
