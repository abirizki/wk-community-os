# Pilot Program Schedule

**Location:** Kelurahan Kebonjati
**Duration:** 4 Weeks

---

## Week 0: Preparation

*   **Activity:** Finalize pilot scope, users, and success criteria.
*   **Activity:** Set up the pilot technical environment.
*   **Activity:** Generate and verify the complete demo dataset.
*   **Activity:** Create pilot user accounts.
*   **Milestone:** **Pilot Environment Ready.**

## Week 1: Training & Onboarding

*   **Activity:** Conduct training sessions for all user groups (Kelurahan, RW, RT, Citizens).
*   **Activity:** Distribute login credentials and user guides.
*   **Activity:** Official pilot launch. Users begin to use the system for daily tasks (SKTM & Complaint flows).
*   **Milestone:** **Pilot Live.** All users have successfully logged in.

## Week 2: Active Use & Feedback Collection

*   **Activity:** Users continue to use the system for all letter and complaint requests.
*   **Activity:** Weekly check-in meeting with all pilot users.
*   **Activity:** Distribute mid-point feedback form.
*   **Milestone:** **First set of end-to-end transactions completed.**

## Week 3: Intensive Use & Issue Tracking

*   **Activity:** Focus on testing edge cases and less common features.
*   **Activity:** Weekly check-in meeting, focusing on issues logged.
*   **Activity:** Begin analysis of analytics data generated during the pilot.
*   **Milestone:** **Issue log populated and prioritized.**

## Week 4: Evaluation & Wrap-up

*   **Activity:** Distribute final evaluation forms.
*   **Activity:** Conduct final stakeholder meeting to present findings.
*   **Activity:** Measure results against success criteria.
*   **Milestone:** **Go/No-Go decision for full production launch.**
