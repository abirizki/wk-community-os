# Release Notes - Version 1.0.0

**Release Name:** "Kebonjati Pilot"
**Release Date:** August 3, 2026

This is the inaugural public release of the WK Community OS, a fully integrated digital platform for local government services. This version includes all core modules required for the Kelurahan Kebonjati pilot program.

## Key Features

- **Digital Letter Service:** Citizens can now request official letters like SKTM and Surat Domisili online, with a full approval workflow from RT to Kelurahan, culminating in an automatically generated, QR-verified PDF.
- **Public Complaint System:** A transparent system for citizens to submit and track public service complaints, with automated assignment and resolution workflows.
- **Role-Based Dashboards:** Real-time dashboards provide RT, RW, and Kelurahan officials with the key metrics and action items they need for daily operations.
- **Automated Notifications:** All parties are kept informed at every step of a process via an in-app inbox and other channels.
- **Robust Administrative Toolkit:** Includes tools for managing users, generating demo data, performing backups, and monitoring system health.
