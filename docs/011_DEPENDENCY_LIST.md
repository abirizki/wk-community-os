# Dependency List

**Document ID:** PILOT-01-011
**Version:** 1.0
**Date:** 2026-08-04

---

## 1. Overview

This document lists all external and internal dependencies required for the successful execution of the Kebonjati Pilot.

## 2. Dependencies

*   **Technical Dependencies:**
    *   A provisioned and active Google Workspace account for hosting the application.
    *   Stable internet connectivity at the Kelurahan office.
    *   Sufficient Google Drive storage for generated documents and backups.
*   **Human Resource Dependencies:**
    *   Availability of all identified pilot users (RT, RW, Kelurahan staff) for the scheduled training sessions.
    *   Availability of the implementation team members as per the resource plan.
*   **Data Dependencies:**
    *   Access to a sample of anonymized citizen data for seeding the pilot environment.
*   **Organizational Dependencies:**
    *   Formal approval and support from the Lurah of Kebonjati.
