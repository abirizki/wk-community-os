# Release Notes

## Version 1.0.0 - "Kebonjati Pilot"

**Release Date:** August 3, 2026

---

### New Features

This is the inaugural release of the WK Community OS, featuring a comprehensive suite of modules for local government administration.

*   **Citizen & Household Management:** Full CRUD functionality for managing citizen and household data.
*   **Letter Service:** End-to-end digital letter request system, featuring SKTM and other common letter types with PDF generation and QR code verification.
*   **Complaint Service:** Structured public complaint submission, tracking, and resolution workflow.
*   **Workflow Engine:** A robust, generic engine powering all approval processes.
*   **Notification Center:** Event-driven notifications via Inbox and other channels.
*   **Analytics & Dashboards:** Role-based dashboards for RT, RW, and Kelurahan with performant, cached data.
*   **Demo Data & Deployment:** Comprehensive toolkits for generating demo data and managing application deployments.

### Improvements

*   Initial stable release.

### Bug Fixes

*   No previously known bugs.

### Known Issues

*   The system's performance is dependent on Google Apps Script quotas. High-volume simultaneous requests may experience throttling.
*   The user interface is currently conceptual and requires implementation with a dedicated frontend framework for the best user experience.
