## 1. Overview

This document outlines the communication strategy for the Kebonjati Pilot to ensure all stakeholders are kept informed and engaged throughout the project lifecycle.

## 2. Communication Channels & Frequency

| Communication Type | Channel | Audience | Frequency | Owner |
| :--- | :--- | :--- | :--- | :--- |
| **Project Status Report** | Email | Project Sponsor, Kelurahan Leadership | Weekly | Project Manager |
| **Weekly Check-in Meeting** | Google Meet | Implementation Team, User Coordinators | Weekly | Project Manager |
| **Urgent Technical Issues** | WhatsApp Group | Technical Lead, Developer, Tester, Operator | As Needed | Technical Lead |
| **General User Support** | WhatsApp Group | All Pilot Users, Coordinators, Trainer | As Needed | Coordinators / Trainer |
| **Formal Announcements** | Email / Official Memo | All Stakeholders | At Milestones | Project Manager |
| **Issue & Risk Tracking** | `IssueRegister.md`, `RiskRegister.md` | Implementation Team | Continuously | Project Manager |

## 3. Key Meetings

*   **Pilot Kick-off Meeting:** To officially start the pilot and align all participants.
*   **Weekly Check-in Meetings:** To review progress, discuss issues, and plan for the upcoming week.
*   **Final Evaluation Meeting:** To present the pilot results and make a Go/No-Go recommendation.
